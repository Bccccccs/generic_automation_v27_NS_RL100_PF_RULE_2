## 2. 明确符号含义

B02 已给出当前符号约定，建模模板中需要按这个口径写明，避免后续把 `J` 和 `JET` 混用。

| 符号 / 名称 | 含义 |
| --- | --- |
| `J01..J24` | STAR 中的喷气口边界，是真实喷气质量流量入口对象。 |
| `JET01..JET24` | STAR 中的底部受力区域，不是喷气口。 |
| `JET_01..JET_24` | 统一动作表中的喷气开关列；落到 STAR 时应映射到 `J01..J24`。 |
| `cmd_massflow_01..24` | 动作表给 STAR 的指令质量流量，单位 `kg/s`。 |
| `actual_massflow_01..24` | STAR 实际质量流量回读，不能用 `cmd_massflow_*` 代替。 |
| `Fz_S1L..Fz_S3R` | 六个底部区域的 `Laboratory +Z` 压力+剪切力，单位 `N`。 |
| `Fz_Total` | 当前 `Fz` report，覆盖 `JET01..JET24 + tail`，不是严格整车全表面升力。 |
| `Jet_Reaction_Z` | 覆盖 `J01..J24` 喷气口的 `Laboratory +Z` 压力+剪切力，单位 `N`。 |

当前已确认的方向：

- Z 向力 report：`Laboratory [0.0, 0.0, 1.0]`。
- `Drag_Total`：`Laboratory [1.0, 0.0, 0.0]`。
- `Pitch_Moment`：绕 `Laboratory [0.0, 1.0, 0.0]`，力矩中心 `[29.0, 0.0, 1.52] m`。
- `Roll_Moment`：绕 `Laboratory [1.0, 0.0, 0.0]`，力矩中心 `[29.0, 0.0, 1.52] m`。

建模侧需要确认：模板、report 名称和导出列名是否都遵循上述符号含义。

## 3. 加入质量流量入口

建模模板中需要把 `J01..J24` 加入为质量流量入口，而不是把喷气动作施加到 `JET01..JET24` 底部区域。

当前 B02 口径：

- `J01..J24` 是喷气口；
- `JET01..JET24` 是底部区域；
- `JET_XX` 控制列应映射到 `JXX`；
- 当前 `J01` 已确认可设为质量流量入口；
- `J01` 质量流率方法为常数，示例值 `2.57 kg/s`；
- 质量流量正值 `+2.57 kg/s` 已确认表示喷入计算域。

建模侧需要补齐：

1. 在模板中把全部 `J01..J24` 设置为可由动作表控制的质量流量入口。
2. 明确每个 `cmd_massflow_XX` 到 `JXX` 的一一映射，避免编号错位。
3. 导出或新增 `actual_massflow_01..24` monitor，用于回读真实质量流量。
4. 在 manifest 或模板说明中写清质量流量正负号：正值表示喷入计算域。
