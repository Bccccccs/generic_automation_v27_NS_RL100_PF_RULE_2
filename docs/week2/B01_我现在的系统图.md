# B01 我现在的系统图

这套系统现在有两种数据来源：真实 STAR-CCM+ 和本地 MockDynamic24x6。两者最终都要
变成同一种标准数据，再进入降维、ROM 和控制器，最后输出 24 路喷气指令。

```mermaid
flowchart LR
    A["STAR-CCM+ / MockDynamic24x6"] --> B["原始数据"]
    B --> C["数据标准化"]
    C --> D["降维"]
    D --> E["ROM"]
    E --> F["控制器"]
    F --> G["喷气指令"]
    G --> A
```

## 每个箭头传递什么

| 箭头 | 数据内容 | 单位 | 维度 |
| --- | --- | --- | --- |
| `STAR / Mock -> 原始数据` | STAR 输出 report、传感器、流场快照；Mock 输出 6 路虚拟载荷响应。 | STAR: `N`、`N*m`、`Pa`、`m/s`、`kg/s`、`s`；Mock: 无量纲虚拟响应，写入标准列时按载荷响应处理。 | 每个控制窗口一条全局/载荷记录；Mock 核心输出是 `y(t) in R^6`；未来压力传感器是 `n_sensor` 行；流场快照是网格点/单元上的多变量场。 |
| `原始数据 -> 数据标准化` | 把不同来源字段映射成统一 case bundle：`timeseries.csv`、可选 `pressure_sensors.csv`、`flow_snapshots/`。 | `physical_time` 为 `s`；`JET_01..JET_24` 为喷气命令，当前可为 0/1 或归一化幅值，真实 STAR 可映射到 `kg/s`；`Fz_*`、`Fz_Total` 为 `N`；`Drag_Total` 为 `N`；力矩为 `N*m`；压力为 `Pa`。 | `timeseries.csv`: `T x 39` 必填列，包含 `2` 个时间列、`24` 个喷气列、`6` 个局部载荷列、`6` 个全局输出列、`solver_status`；`pressure_sensors.csv`: 至少 `N x 4`；`flow_snapshots/`: 每个时间片一个场文件。 |
| `数据标准化 -> 降维` | 从标准表和快照中抽取状态向量，例如载荷、阻力、压力传感器、POD/PCA 系数、历史窗口特征。 | 保持原物理单位或先做无量纲化；进入模型前建议保存归一化参数。 | 原始观测可从几十维到网格级高维；降维后目标是 `z(t) in R^r`，其中 `r` 通常远小于原始维度，例如 `r=8..64`。 |
| `降维 -> ROM` | 低维状态 `z(t)`、当前/历史喷气输入 `u(t)`、时间步或窗口长度。 | `z(t)` 常为无量纲系数；`u(t)` 为 24 路喷气命令，0/1、归一化幅值或 `kg/s`；`dt/window_duration` 为 `s`。 | 状态 `R^r`；输入 `u(t) in R^24`；如果带历史延迟，则输入可拼成 `R^(24*K)`。 |
| `ROM -> 控制器` | ROM 预测的下一步/未来多步响应，例如低维状态、6 路载荷、总阻力、姿态力矩、约束风险。 | 载荷 `N`、阻力 `N`、力矩 `N*m`、压力 `Pa`，或归一化后的预测值。 | 单步预测可以是 `R^6` 或扩展输出 `R^m`；多步预测是 `H x m`，`H` 是控制预测步长。 |
| `控制器 -> 喷气指令` | 控制器选出的 24 路喷气动作，写入 `actuation_schedule.csv` 或未来 STAR 运行时控制文件。 | 当前本地调度多为 0/1 或归一化幅值；真实喷口最终要换算成质量流量 `kg/s`、速度 `m/s`、占空比 `0..1` 或频率 `Hz`。 | 每个窗口 `u(t) in R^24`；当前 B03 调度是 `80 x 24`，其中 72 个激励窗口每行 3 个开启，8 个参考窗口全零。 |
| `喷气指令 -> STAR / Mock` | 将 `JET_01..JET_24` 应用到真实喷口边界或 MockDynamic24x6 输入。 | Mock 接收归一化 24 维输入；STAR 接收真实边界条件单位，例如 `kg/s` 或 `m/s`。 | 每个控制窗口一条 24 维向量；MockDynamic24x6 固定 `24` 输入、`6` 输出；STAR 侧对应 24 个喷气区/边界/profile。 |

## 当前代码里已经固定的接口

- 24 路喷气列：`JET_01 ... JET_24`。
- 6 路载荷输出：`Fz_S1L`、`Fz_S1R`、`Fz_S2L`、`Fz_S2R`、`Fz_S3L`、`Fz_S3R`。
- 标准全局输出：`Fz_Total`、`Drag_Total`、`Pitch_Moment`、`Roll_Moment`、`Jet_Reaction_Z`、`solver_status`。
- MockDynamic24x6 是 `24` 输入、`6` 输出；STAR 数据通过共享 mapper 映射到同一套列名。
- `CaseSchema` 已预留 `pressure_sensors.csv` 和 `flow_snapshots/`，用于以后接压力测点和流场快照。
